## 3. Implementasi Kode & Antarmuka

- **JSON Data Source (`data/desa-wisata.json`):**  
  Setiap entri memuat path lokal `image: "/img/villages/{id}.jpg"` dan teks atribusi `imageCredit`.
- **Komponen Timeline (`ItineraryTimeline.tsx`):**  
  Menampilkan badge kredit fotografer semi-transparan di sudut kanan bawah thumbnail foto.
- **Komponen Peta (`LeafletMap.tsx`):**  
  Menampilkan badge atribusi pada thumbnail pop-up desa aktif.
- **Pengecekan Otomatis (`tests/image-duplicates.test.mjs`):**  
  Memverifikasi seluruh 28 desa memiliki URL gambar unik tanpa duplikasi.
